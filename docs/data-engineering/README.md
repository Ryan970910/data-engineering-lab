# Course source and practice files

Study at https://ryan970910.github.io/data-engineering-lab/ or start with [MANUAL.md](MANUAL.md).

This English course assumes independent Python and basic SQL. It teaches concepts before tools through 20 modules, guided labs, independent challenges, failure investigations and evidence-based assessment.

Authoritative chapters live in lessons/. MANUAL.md explains navigation and setup; ASSESSMENT.md defines assessment. The website renders these sources.

## Practice boundaries
- lab.py: offline fictional pipeline, Python standard library.
- sql_lab.py: read-only SQLite query practice with exact identity checks.
- spark_exercise.py: learner implementation scaffold, deliberately incomplete.
- dags/club_training.py: Airflow 3 single-host demo, no production integrations.
- env.sh: Linux environment paths and D-drive caches.
- verify_course.py: author baseline checks, never a learner certificate.

See REFERENCES.md for versions and verification limits. Keep generated work under .learning-runtime. Do not install tools into the business project's environment or publish real member data.
