# Learning website

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
User confirmed plain static HTML/CSS/JavaScript, published with GitHub Pages.

## Users and Purpose
The maintainer writes Python independently and knows basic SQL, but is new to data engineering, Airflow and PySpark. Teach concepts before tools through 20 detailed English modules, project-shaped experiments and independent assessment.

## Capabilities and Constraints
- The private production repository remains private. User authorized a separate public repository containing only the learning website and synthetic exercises.
- Numbered lessons/*.md chapters are instructional authorities; MANUAL.md indexes the course and ASSESSMENT.md defines practical assessment.
- Read and self-check on a phone; execute real exercises on a computer. The website does not run Spark or Airflow, connect to CRM, or certify mastery.
- No server, account, or automatic cross-device progress synchronization. Local progress can be exported and imported.
- Course changes must not change production code, configuration, or business rules.

## Brand Commitments
Continue the user's preference for a clean Apple-like reading interface. All instructional and interface content is English; allow long chapter labels to wrap.

## Evidence on Hand
docs/data-engineering contains the complete manual, assessment guide, synthetic standard-library pipeline, Spark exercise and Airflow demo. Author validation is not learner evidence.
